# 설치 및 서버 구성 안내

## 1. 서버 환경

- 운영체제: Windows Server 2016
- 웹메일 프로그램: Roundcube Webmail 1.7.4
- 메일 서버: hMailServer
- 외부 발신 메일 서비스: SMTP2GO
- 프로그래밍 언어: PHP
- 보안 연결: SSL/TLS
- 도메인: shownpil.cloud

## 2. 시스템 구성

SHONPIL WEBMAIL은 Windows Server 환경에서 운영되는 웹메일 서비스입니다.

- Roundcube: 웹 브라우저에서 이메일을 확인하고 관리하는 인터페이스
- hMailServer: 이메일 수신 및 발신을 처리하는 메일 서버
- SMTP2GO: 외부로 발신하는 이메일의 전송을 중계하는 서비스
- SSL/TLS: 지원되는 연결에서 통신 내용을 보호하는 보안 기술
- DNS: 도메인과 메일 서비스의 연결 정보를 관리하는 시스템

## 3. 구축 과정

1. Windows 서버 준비
2. 웹 서버 및 PHP 환경 구성
3. Roundcube 설치 및 설정
4. hMailServer 설치 및 설정
5. IMAP 및 SMTP 연결 설정
6. 외부 발신 메일 중계 서비스 설정
7. 도메인 DNS 레코드 설정
8. SSL/TLS 인증서 설정
9. 이메일 수신 및 발신 테스트
10. 모바일 메일 앱 연결 테스트

## 4. 보안 관리

다음 정보는 공개 저장소에 업로드하지 않습니다.

- 이메일 계정 비밀번호
- 서버 관리자 계정 및 비밀번호
- SMTP2GO 인증 정보
- SSL/TLS 인증서 개인 키
- 실제 운영 환경의 설정 파일
- 이메일 내용 및 첨부파일
- 데이터베이스와 메일 데이터 백업

설정 예시를 공개할 때는 실제 인증 정보 대신 예시 값을 사용합니다.
